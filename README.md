# xdg-redirect

`xdg-redirect` is an Emacs Lisp package designed to organize files and
directories generated by Emacs packages, moving them to locations that follow
the [XDG Base Directory specification](https://specifications.freedesktop.org/basedir-spec/basedir-spec-latest.html).

This package helps keep your home directory and the Emacs configuration
directory (`~/.emacs.d` or `~/.config/emacs`) clean by separating persistent
data, cache files, configurations, and runtime files into their proper places.

## Installation

Add the package directory to your `load-path` and load it in your initialization file:

```elisp
(add-to-list 'load-path "/path/to/xdg-redirect")
(require 'xdg-redirect)
```

## Usage

### Locating files in XDG directories

You can use the `locate-user-emacs-*-file` functions to get paths within the XDG
standard folders. By default, they use a subdirectory named `emacs/` inside the
respective XDG folder (e.g., `~/.cache/emacs/`).

```elisp
;; Set the customization file location to ~/.config/emacs/custom.el
(setq custom-file (locate-user-emacs-config-file "custom.el"))

;; Set the location for backup or cache files
(setq auto-save-list-file-prefix (locate-user-emacs-cache-file "auto-save-list/.saves-"))
```

Available functions:

- xdg-redirect-locate-config-file (locate-user-emacs-config-file)

- xdg-redirect-locate-data-file (locate-user-emacs-data-file)

- xdg-redirect-locate-cache-file (locate-user-emacs-cache-file)

- xdg-redirect-locate-runtime-file (locate-user-emacs-runtime-file)

### Redirecting existing variables

Many packages define variables for file paths. You can easily redirect them
using the provided macros, which modify the original variable's value in place.

```elisp
;; Move the recentf history file to the XDG cache
(xdg-redirect-to-emacs-cache recentf-save-file)

;; Move the project.el project list to the XDG data folder
(xdg-redirect-to-emacs-data project-list-file)

;; Redirect cookies from the url package
(xdg-redirect-to-emacs-data url-cookie-file)
```

Available macros:

- xdg-redirect-to-emacs-config

- xdg-redirect-to-emacs-data

- xdg-redirect-to-emacs-cache

- xdg-redirect-to-emacs-runtime

### Customization

You can change the directory prefix (which is "emacs" by default), to be added
to the XDG user directories, and update the active base paths:

```elisp

;; Change the prefix from "emacs" to "my-emacs" and update internal directories
(xdg-redirect-set-directory-prefix "my-emacs" t)
```
